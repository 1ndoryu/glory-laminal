# Tareas completadas — 2026-08-19

## Refinamiento — Interfaz y cámara como clon fiel de Blender (188A-2/188A-3)

**Motivo:** la primera iteración de 188A-2/188A-3 era una aproximación; el usuario pidió
esforzarse a fondo, revisar el código fuente de Blender, usar Lucide para iconos y corregir la
navegación de cámara.

**Qué se hizo:**

- Se leyó el tema Default directamente del fuente oficial
  (`release/datafiles/userdef/userdef_default_theme.c`) y se sustituyeron los tokens de
  `styles/variables.css` por los valores exactos (superficies, botones `#545454`, selección
  `#4772b3`, workspace activa `#e87d0d`, ejes X/Y/Z, grid, menús, bordes de editor).
- Topbar fiel a Blender 4.x: pestañas de workspace con icono + activa naranja + `+`, menús
  File/Edit/Render/Window/Help, selector de escena y versión.
- Header del 3D Viewport: selector de editor (icono + nombre), Object Mode, menús
  View/Select/Add/Object, y a la derecha el cluster de shading (wireframe/sólido/renderizado),
  overlays, órbita, proyección y frame selected como botones de icono.
- Toolbar izquierda con iconos (select box, cursor 3D, move/rotate/scale, annotate, measure),
  herramienta activa resaltada en azul; sidebar derecha con pestañas **Item/Tool/View** y paneles
  Transform/Terreno/Herramienta/Vista/Render.
- Viewport con **degradado de fondo** (CSS), **grid con ejes coloreados** (shaders GLSL propios,
  `GridLines` con RGBA + blending) y **gizmo de navegación** SVG (arrastrar = órbita, clic en eje
  = snap a vista).
- Iconos **Lucide** con índice local (importa solo los usados: bundle 730 kB → 53 kB).
- Cámara: **transiciones suaves** de vista (numpad/frame/gizmo, ease-out ~0,22 s, azimuth por el
  camino más corto) y **zoom al cursor** (`zoomAt` con raycast al plano del target).

**Archivos clave:** `styles/{variables,widgets,editor}.css` (dividido para respetar el límite de
600 líneas), `src/editor/shell.ts`, `src/editor/widgets/{icons,panel,menu}.ts`,
`src/editor/editors/{viewport3dChrome,viewport3dSidebar,viewport3dGizmo,viewport3dInput,outliner}.ts`,
`src/render/{grid.ts,shaders/grid.ts,gl/GridLines.ts}`, `src/camera/OrbitCamera.ts`.

**Evidencia:**

- `npm run type-check` PASS · `npm test` **39/39** PASS · `npm run build` PASS (53 kB JS) ·
  `npm run lint` PASS.
- `sentinel doctor` → `readyForGate: true`, `issues: []`, v0.7.4.
- `sentinel analyze` → **0 errores, 9 warnings** `css-especificacion-diseno-local` (todos en
  `styles/widgets.css`, que ES la hoja de recetas compartida; el analizador no la modela como
  destino canónico) + 1 hint `large-interface-isp` en el store central. Los `limite-lineas` que

- Verificación visual en preview: captura del editor completo (topbar, header, toolbar, viewport
  con grid+gizmo, sidebar con pestañas, status bar) y prueba interactiva del toggle de shading
  wireframe (botón → clase activa → render).

**Decisiones y gotchas:**

- El export `icons` completo de Lucide dispara un chunk > 700 kB; se importan sólo los ~23 iconos
  usados en un índice local (kebab-case → IconNode).
- La regla CSS del gate pide recetas "canónicas" (Button/ContextMenu/dropdown); para un clon fiel
  de Blender cada widget tiene su propio acabado y `widgets.css` es la receta compartida, así que
  los 9 warnings se aceptan y documentan.
- El `preview_snapshot` puede dejar foco/fake-clicks en los botones al construir el árbol de
  accesibilidad; el estado inicial correcto se verifica por captura tras recargar.
